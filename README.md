# سعيد ناصر — رحلة الواحة

لعبة منصات عربية تعمل مباشرة في المتصفح، وتأخذ اللاعب في رحلة عبر ثلاث بيئات عُمانية مليئة بالمهام والعقبات والأعداء.

## المزايا

- ثلاث مراحل مستوحاة من البيئة العُمانية.
- مهام ومفاتيح ونجوم ونظام نقاط متدرج.
- قفز وإطلاق واندفاع مع مؤثرات صوتية وحركية.
- تحكم بلوحة المفاتيح وأزرار لمس للهواتف والأجهزة اللوحية.
- حفظ أفضل نتيجة محليًا في المتصفح.
- ملف واحد خفيف يعمل دون تثبيت أو خادم خلفي.

## التشغيل

افتح ملف `index.html` في أي متصفح حديث، أو فعّل GitHub Pages لتشغيل اللعبة عبر رابط مباشر.

## التحكم

| الإجراء | لوحة المفاتيح |
| --- | --- |
| الحركة | الأسهم أو A / D |
| القفز | Space |
| الإطلاق | F |
| الاندفاع | Shift |

تظهر أزرار لمس تلقائيًا عند تشغيل اللعبة على الهاتف أو الجهاز اللوحي.

## التقنيات

- HTML5 Canvas
- CSS3
- JavaScript دون أطر عمل
- تصميم عربي متجاوب من اليمين إلى اليسار
